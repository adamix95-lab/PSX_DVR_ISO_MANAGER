INSTALACJA / AKTUALIZACJA:
  1. Zrob kopie calej dzialajacej instalacji PP.DVRISO.
  2. Przy aktualizacji podmien przede wszystkim sam
     DVR_ISO_MANAGER_HDD.ELF, jesli reszta juz dziala.
     Zachowaj swoje BOOT.CNF, BOOT_RECOVERY.CNF, config/,
     modules/, ART/, COVERS.IDX, COVER_SCAN.LOG i NET_PROBE.CNF.
  3. Dla nowej, WLASNEJ partycji aplikacji hdd0:PP.DVRISO
     skopiuj zawartosc PP.DVRISO-FILES do jej korzenia.
     NIE kopiuj zewnetrznego folderu paczki jako podfolder.
  4. Uruchom ELF przez wLaunchELF z poprawnie zamontowanej partycji.
     Skrot/instalator XMB jest osobnym, niepotwierdzonym zadaniem.
  5. Gry musza juz istniec w: dvr_pfs0:/ISO/.
  6. W celu pobrania ART uruchom PC ART Server i ustaw LAN
     w pliku NET_PROBE.CNF.

STEROWANIE:
  GORA/DOL       wybor gry
  LEWO/PRAWO     strony, maksymalnie 12 gier na stronie
  SELECT         SYSTEM / ENGLISH
  TROJKAT        skanowanie gier, aktualizacja indeksu
  X po skanie    potwierdz pobieranie brakujacych okladek
  O po skanie    pomin pobieranie
  X na liscie    zapisz/zweryfikuj BOOT.CNF i uruchom gre
  KWADRAT        test konfiguracji DVR_TEST.CNF
  START          wyjscie z aplikacji

DLACZEGO DWA POBRANIA (40 + 4)?
  Limit kolejki pobierania to 40 obrazow na sesje, nie limit biblioteki.
  Po pierwszej serii wykonaj ponownie skan, aby pobrac pozostale.

BEZPIECZENSTWO:
  * Manager czyta dvr_pfs0:/ISO/ i nie modyfikuje obrazow gier.
  * ART/ oraz CNF/indeksy zapisywane sa na oddzielnym PP.DVRISO.
  * Program nie tworzy ani nie formatuje partycji Sony.
  * NETFIX/PNG CRC i bezpieczny zapis .PART sa nadal aktywne.
  * SYSTEM i ENGLISH wymagaja zgodnego kompletu config/ i modules/.
  * Komunikaty diagnostyczne przy pobieraniu moga nadal byc widoczne;
    na gotowej liscie gier pojawia sie tylko liczba okladek.
