# DESR7000-DVR

Projekt eksperymentalny dla Sony PSX DESR-7000 korzystający z obsługi partycji/obszaru DVR w Neutrino.

## Cel

Testowanie poprawki [Neutrino PR #228](https://github.com/ps2max32/neutrino/pull/228) autorstwa pcm720 na konsoli PSX DESR-7000 z DVRPwned.

## Wyniki na dzień 15.10.2026
- pomyślne zintegrowanie łatki od pcm720 z Neutrino za pomocą ChatGPT
- testy na konsoli PSX DESR 7000, FW 1.31, ATA EXPRESS + microSD 512GB, DVRPwned, partycja PS2 - 128GB
- przetestowano na 8 grach, 6 w formacie CD i 2 DVD, gry uruchamiają się z powodzeniem

## Źródła i autorzy

- Neutrino: https://github.com/ps2max32/neutrino
- PR #228 (pcm720): https://github.com/ps2max32/neutrino/pull/228

Ten repozytorium zawiera tylko konfigurację budowania i dokumentację projektu; właściwe źródła Neutrino są pobierane podczas kompilacji.
